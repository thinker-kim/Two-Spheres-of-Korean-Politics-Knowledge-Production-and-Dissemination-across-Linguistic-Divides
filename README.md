## About the study

This study examines knowledge production and dissemination across Korean and English linguistic spheres using research on Korean politics. The source corpus comprises 15,268 articles across 247 journals: 10,477 written in Korean and 4,791 written in English. Linguistic spheres are defined by written language, journal indexing, and publisher location.

| Analysis | Focus |
| --- | --- |
| RQ1: Knowledge production | Research-topic distributions and topic skew, measured using the Normalized Difference Score (NDS). |
| H2: Outgoing citations | Local-reference shares and references cited across both linguistic spheres. |
| H3: Incoming citations | Visibility, locality, and the citation-based prestige of citing outlets. |

Topic modeling uses English abstracts from articles in both written-language groups. The 35-label classification includes 34 substantive topics and an outlier category. H2 and H3 use Mann–Whitney U tests. The main manuscript reports comparisons by written language; the supplementary material also reports comparisons by journal indexing and publisher location.

## Data and code

The replication package contains article metadata, outgoing references, incoming citations, archived topic assignments, independent Python analysis scripts, variable definitions, and an analysis guide. A Harvard Dataverse link will be added once available.

Analyses use archived topic assignments. Re-fitting the topic model may produce different assignments and map positions because of stochastic components and differences in software versions and computational environments. Topic identifiers in the interactive map follow the fitted model and may differ from remapped identifiers in exported tables.
